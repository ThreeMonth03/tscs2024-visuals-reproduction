# Official township classification

`area_classification.csv` transcribes all 368 townships from the 2020 township digital-development classification report. It contains no respondent records, sample counts or sampled-location list.

- Source: [Ministry of Digital Affairs report page](https://moda.gov.tw/digital-affairs/digital-service/dv-survey/2236).
- Report: the National Development Council's 2020 township digital-development classification; a licensed copy is catalogued in `references/`.
- Rights: [Ministry website open-data declaration](https://moda.gov.tw/announcement/publicdeclare/951), CC0 1.0.
- Four classes contain 79, 89, 97 and 103 townships. Class 1 is digitally mature; classes 2–4 form the non-mature area group used by this analysis.
- `printed_page` identifies the report page used for transcription. Township names are matched to value labels supplied by the user's official survey file; unmatched locations stop analysis.

This geographic classification describes townships, not individual residents' abilities or service use.
