# References and redistributable full texts

This directory provides **23 references** supporting the study. It includes **six redistributable original PDFs**; other entries link to official publication pages, DOIs, or institutional full texts. The bibliography is available in [cited_references.bib](cited_references.bib). Download sources, license evidence, file hashes, and availability are recorded in [references.json](references.json). Checked on 2026-10-28. Official Chinese reference titles are retained in their original language.

PDFs are unmodified: no pages, text, or margins have been removed. Public reading access does not itself permit re-uploading, so articles without confirmed redistribution rights are linked rather than included. Each PDF retains its original copyright and license, separate from the analysis code license; any stated restrictions on third-party material also apply.
